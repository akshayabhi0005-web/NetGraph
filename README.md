# NETGRAPH — Career Intelligence & Interactive 3D Graph Platform

**Mining Hidden Relationships Between Skills, Technologies & Career Opportunities**

NETGRAPH is a data mining-based career intelligence platform developed to explore multi-dimensional relationships between candidate skills, modern technology stacks, academic and open-source project repositories, and real-world career pathways.

---

## 🌟 Key Features

### 🌐 Public Experience
- **Interactive 3D Hero Graph**: WebGL-powered 3D spherical network visualization supporting mouse drag, touch rotation, zoom, auto-rotation, and interactive node inspection.
- **Features Grid**: Comprehensive overview of profile-based analysis, role matching, gap analysis, and relationship discovery.
- **Methodology Stepper**: Clear breakdown of the 3-step pipeline: profile building, pattern matching, and gap exploration.
- **Academic Foundation**: Ethical and heuristic disclosures for data mining and career trajectory mapping.

### 🔐 Authenticated Platform Experience
- **Analytics Dashboard**: Metric overviews, Recharts visualizations, and research activity stream.
- **Candidate Profile**: Structured management for education, experience, technical skills, project repositories, and career preferences.
- **Skill Analysis Engine**: Simulated data mining engine mapping skills across projects, resumes, and tools.
- **Career Matches & Alignment**: In-depth role cards with predicted alignment percentages and represented vs. missing skill diagnostics.
- **Skill Gap Diagnostics**: Targeted role benchmarks, coverage meters, and recommended bridge opportunities.
- **Full 3D Graph Explorer**: Three.js force graph with search, category filtering, relationship exploration, and collapsible node inspection.
- **Career Reports**: Formatted career analysis reports ready for export.
- **Resume Builder**: Guided wizard with ATS-friendly templates and preview.

## 🛠️ Technology Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, PostCSS
- **UI Components**: Radix UI / Shadcn UI, Framer Motion, Lucide Icons
- **3D Graphics**: Three.js / React Three Fiber / Drei
- **Data Visualization**: Recharts
- **Package Manager**: pnpm / npm

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v18+ 
- [pnpm](https://pnpm.io/) or [npm](https://www.npmjs.com/)

### Installation & Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/akshayabhi0005-web/NetGraph.git
   cd NetGraph
   ```

2. **Install dependencies**:
   ```bash
   pnpm install
   # or
   npm install
   ```

3. **Start the development server**:
   ```bash
   pnpm dev
   # or
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.

5. **Build for production**:
   ```bash
   pnpm build
   # or
   npm run build
   ```
